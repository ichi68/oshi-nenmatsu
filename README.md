# 限界オタクの年末調整 〜推しの周年まであと30日〜

推し活のノリで、年末調整の「どの書類に何を書くか」を覚えるブラウザゲームです（1プレイ3〜5分、令和8年分）。

**公開URL**：https://oshi-nenmatsu.vercel.app

## 遊び方

1. 「はじめる」を押して、オタク属性診断の4問に答える
2. 散らかった部屋から、年末調整の書類だけをタップして集める（推しグッズは押さないこと）
3. 集めた書類を、正しい提出先のボタンに振り分ける
4. 提出期限（30日）までに終わらせて、達成度と称号をチェック

推し活費用は控除の対象ではありません。

## 手元で動かす

`index.html` をダブルクリックすると、ブラウザでそのまま遊べます。インストールやビルドは不要です。

## ファイル構成

```
index.html      画面の骨組み
css/style.css   見た目
js/data.js      問題・解説・コメント・称号・豆知識など、画面に出す文章すべて
js/main.js      画面切替、タイマー、判定、結果計算
assets/ogp.png  URL共有時のサムネイル
SPEC.md         仕様書
```

## 問題やコメントの追加方法

1. `js/data.js` の `CARDS` に同じ形のオブジェクトを足す（`answer` は `CATEGORIES` の id、推し活費用なら `oshi: true` と `answer: 'none'`）
2. コメントは `COMMENTS.correct` などの配列に文字列を足すだけ
3. 制度の内容に関わるカードは、追加前に国税庁の資料で確認する
4. GitHub に push すれば、数十秒で公開URLに反映される

## 注意

このゲームは令和8年分の制度をもとに簡略化しています。実際の手続きは勤務先の案内と国税庁の情報を確認してください。推し活費用は所得控除の対象ではありません。
